# 星见雅 · 永恒领域档案

饥荒联机版星见雅模组的静态介绍网站。当前内容对应 0.3.123-drives-v170，包含三套衣装、双材料升级、小无尾伙伴、季节装备及驱动盘、音像店玩法。使用 HTML、CSS、JavaScript 和本地图片，无需安装依赖或构建。

## 发布

在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。推送到 `main` 后自动部署。

网站地址：https://xbwsh.github.io/miyabi-mod-guide/

## 文件

- `index.html`：介绍与数值内容。
- `style.css`：布局、移动端和主题。
- `app.js`：搜索、衣装切换、主题选择与群号复制。
- `assets/`：随网站保存的图片。
- `particles.js`：桌面端表情点阵互动，窄屏隐藏并按可见性暂停。
- `combo-preview.js`：普攻与飞雪动画预览及独立暂停控制。
- `.github/workflows/pages.yml`：自动部署配置。

默认深色主题，尊重访客保存的手动选择。
